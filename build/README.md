# Build Resources

This directory contains build resources for the Electron app.

## Icons

To add a custom icon for the Windows installer:

1. Create or obtain an icon file (256x256 pixels or larger)
2. Convert to ICO format with multiple sizes (16x16, 32x32, 48x48, 256x256)
3. Save as `build/icon.ico`

If no icon is provided, electron-builder will use a default icon.
